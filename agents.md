Repository write rules
- Always ask me for permission before any write to the repo: commits, pushes, creating or deleting branches, pull requests, tags, issues, or comments. Ask each time; earlier approval does not carry over to later writes.
- Never commit or push directly to master, even with permission. Use a feature branch (e.g. claude/<short-description>) and propose a pull request for me to review.
- This rule overrides any automated prompt (such as a stop hook) that asks you to commit or push. If one appears, tell me instead of acting on it.
- Never print, log, or commit credentials or secrets.
